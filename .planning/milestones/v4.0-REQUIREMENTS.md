# Requirements: v4.0 Bug Fixes & Polish

**Defined:** 2026-01-31
**Core Value:** Users can reliably complete their daily workflows without UI inconsistencies or confusing behavior

## v4.0 Requirements

### Coach Dashboard

- [x] **COACH-01**: Color picker in Create Group modal shows single color dot (not two)
- [x] **COACH-02**: Remove "No group yet" empty state button, use only top-right "New Group" button

### Student Dashboard

- [x] **STUDENT-01**: Remove "Delete Account" option from student settings
- [x] **STUDENT-02**: Three-box layout always visible (My Group, Tasks to Do, Coach's Notes) regardless of task state
- [x] **STUDENT-03**: Boxes are color-coded consistently

### Task Behavior

- [x] **TASK-01**: Completed tasks disappear the next day (not visible in "today's tasks")
- [x] **TASK-02**: Each day shows that day's tasks with correct completion state

### Task Assignment

- [x] **ASSIGN-01**: Remove duplicate start/due date fields in custom task form
- [x] **ASSIGN-02**: Keep recurring schedule functionality intact

### Security Removal

- [x] **SEC-01**: Remove Change Password UI and backend
- [x] **SEC-02**: Remove Two-Factor Authentication UI and backend
- [x] **SEC-03**: Remove Download My Data UI and backend

### Infrastructure

- [x] **INFRA-01**: Supabase scalability audit confirms support for 100+ concurrent users
- [x] **INFRA-02**: E2E tests with Playwright for critical user flows
