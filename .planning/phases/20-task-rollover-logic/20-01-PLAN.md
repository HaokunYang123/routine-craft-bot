<task type="auto">
  <name>Task 2: Create useDayBoundary hook</name>
  <files>src/hooks/useDayBoundary.ts</files>
  <action>
Create a new hook `useDayBoundary` that:

1. Takes `timezone: string` parameter
2. Uses `useState` to track `currentDateString` (initialized from `getUserTodayDateString`)
3. Uses `useRef` to track previous date for comparison
4. Sets up 60-second polling interval via `useEffect`:
   - On each tick, get current date string via `getUserTodayDateString(timezone)`
   - Compare with previous ref value
   - If changed: update state, update ref, log `[DayBoundary] Day changed`
5. Properly cleans up interval on unmount

Returns:
- `currentDateString`: Today's date in user's timezone
- `yesterdayDateString`: Yesterday's date in user's timezone (computed from `getYesterdayDateString`)

Import from:
- `getUserTodayDateString`, `getYesterdayDateString` from '@/lib/timezone'
- `useState`, `useEffect`, `useRef` from 'react'

IMPORTANT: Use absolute time comparison, NOT incrementing counters (per RESEARCH.md pitfalls about timer drift).
  </action>
  <verify>
TypeScript compiles: `npx tsc --noEmit src/hooks/useDayBoundary.ts`
  </verify>
  <done>
`useDayBoundary` hook exists, polls every 60 seconds, returns `currentDateString` and `yesterdayDateString`, re-renders component when day changes at midnight.
  </done>
</task>
